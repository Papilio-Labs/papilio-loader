Board Recovery

Set Up or Recover Your Board

Use this page to install or recover a board. It installs the Papilio ESP Bootloader and a compatible FPGA-Companion app in one USB operation. Everything happens in this browser tab over USB and your home WiFi. Nothing is installed on your computer, and your WiFi credentials never leave your machine except to the board itself.

Already set up? For everyday use — JTAG SRAM, recovery mode, or OTA firmware updates — use the full Papilio Loader — Web Edition instead.

WebSerial isn't available in this browser. Open this page in Google Chrome or Microsoft Edge (desktop) over HTTPS to flash your board.

Install the Latest A2600 Core

      

      

        Downloads the latest published Atari 2600 FPGA core and writes it to the board's FPGA
        flash. The page first switches the board into the Papilio ESP Bootloader (which does
        the flashing), then returns it to FPGA-Companion. Sent directly from this browser tab — over WiFi if the device's IP is known
        (fastest), or over the USB connection from Step 1/2 if it isn't. No cloud relay either way.
